# Технический аудит: TimePad

## 1. Название ресурса / компании
TimePad — российская платформа для организации мероприятий и продажи билетов.

## 2. Адрес ресурса
https://timepad.ru

## 3. Анализ архитектуры и логики

**Условия проверки:** Wi-Fi, дом, Chrome, 22.09.2026.

- **Backend:** PHP. Виджеты используют Mustache-шаблоны.
- **API:** REST, база `https://api.timepad.ru/v1`. Пример: `GET /v1/events/{event_id}`.
- **Аутентификация:** Bearer token.
- **CDN:** Cloudflare.
- **Виджеты:** JavaScript-библиотека (TWF2), встраивается на сторонние сайты.

## 4. Семантические элементы HTML5

| Элемент      | Количество |
|--------------|------------|
| `<header>`   | 0          |
| `<nav>`      | 0          |
| `<main>`     | 0          |

**Вывод:** сайт практически не использует семантические теги HTML5 —
вёрстка построена на `<div>` с CSS-классами (React SPA). Из семантики
встречаются только `<article>` (карточки событий) и `<footer>`.

Media-запросы: `1200px`, `992px`, `768px`, `480px`.

## 7. Lighthouse

**Условия:** Wi-Fi, дом, Chrome, режим инкогнито, 22.09.2026.

| Категория       | Desktop | Mobile |
|-----------------|---------|--------|
| Performance     | 65      | 9      |
| Accessibility   | 70      | 70     |
| Best Practices  | 73      | 73     |
| SEO             | 92      | 92     |

**Проблемы:** крайне низкий Performance на мобильной версии (9/100) —
большой объём JavaScript, неоптимизированные изображения, медленный LCP.
Accessibility 70 — отсутствие alt-атрибутов и контрастных подписей у части элементов.
